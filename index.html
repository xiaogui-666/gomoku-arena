高级参数

仅在使用「内置引擎」时生效；用于评测时建议调到 100%。

它是怎么让"普通语言模型"下棋的？

  1. 每回合重画棋盘：把 15×15 局面渲染成 ASCII 图（X/O/.），连同坐标体系（列 A-O、行 1-15）一起发给模型。
  2. 给出规则与优先级：能赢就赢 → 对手四连必堵 → 防活三 → 做自己的活三/活四。
  3. 限定输出格式：只准输出 MOVE: H8，避免废话。
  4. 容错解析 + 重试：支持 MOVE: H8、H8、{"row":8,"col":8}、(8,8) 等多种写法；解析出非法点会自动把原因回传给模型重试一次；仍失败则由内置引擎兜底，不会卡住对局。
  5. 可选候选点提示：把引擎算出的 Top5 候选点放进 prompt，弱模型棋力会明显提升（可在高级参数里关闭以做"纯净评测"）。

常见问题

为什么需要跑本地服务？
浏览器直连各家 API 会被 CORS 拦截，且 Anthropic 协议不兼容 OpenAI 格式。本地服务只做转发，不存储你的 Key。
模型老是下到已有棋子上？
开启"候选点提示"，或换更强/更新的模型；连续失败会触发内置引擎兜底。
想接没列出的模型？
选"自定义（OpenAI 兼容）"，填任意 Base URL + Key + 模型名即可，包括 Ollama、vLLM、OneAPI、LiteLLM 等自建网关。
